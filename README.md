# 🗄 Архивариус

![логотип](logo.png)

Программа для наведения порядка на диске с документами. Читает **содержимое**
файлов, предлагает каноническое имя и место по регламенту, собирает карту
переноса, а перемещает **только то, что вы утвердили**. Модель — локальная
Ollama, наружу ничего не уходит. Регламент конкретного отдела живёт в `prompt.md`
(настройте свой корень и регламент в config.json и prompt.md) — для другой организации
достаточно поменять инструкцию и список верхних папок в настройках.

## ✨ Что нового

- **Мульти-корень**: `root_candidates` + автовыбор первого существующего пути —
  один и тот же Google Drive под разными буквами на разных компьютерах больше не ломает запуск.
- **📦 Папка целиком** (Карта): модель видит все имена папки одним запросом и согласует
  их друг с другом; безымянные фото проходят через зрение. CLI: `python app.py folder --path "…" --vision`.
- **🔁 Переразобрать** (Карта): отказы и выбранные строки возвращаются модели без нового
  скана диска; у `suggest` есть флаг `--redo`.
- **🧠 Уроки** (Карта, второстепенная кнопка): правки, отказы и комментарии человека
  превращаются в правила-черновики `learned_rules.md`. В промпт попадают только
  ПОДТВЕРЖДЁННЫЕ человеком строки (помеченные `✓`/`[x]`); свежие авто-уроки — черновики
  и не применяются, пока вы их не одобрите. Уроки уточняют разбор и не могут менять
  формат имени или перечень разделов из `prompt.md`.
- **🩺 Проверить странное** (Карта): детерминированные эвристики просматривают ВЕСЬ
  список и помечают подозрительные строки — мусорное имя (`IMG_2041`, «копия», uuid),
  файл, завалявшийся в развале без разбора, битая цель (нет такой папки на карте),
  уверенное расхождение года в имени и в папке, столкновение двух файлов на одно имя,
  «отмечено, но пусто». Диалог показывает сводку и примеры, а затем мягко перепроверяет
  помеченные строки моделью. Молча ничего не переносится — решение за вами.
- **🔬 Перепроверить глубже** (Карта и Просмотр) теперь идёт в ТРИ ШАГА: модель
  сначала выписывает факты из содержимого, затем из фактов собирает имя, затем
  подбирает папку по карте и соседям — данные уточняются постепенно, а не одним рывком.
  Полный текст, соседи по папке, предложенная папка и ваш комментарий учитываются;
  контекст строится так, чтобы инструкция не обрезалась. Показывает улучшенный вариант
  рядом с первым и обе уверенности; «выдуманная» папка режет уверенность переноса.
- **Две уверенности вместо одной**: в карте колонки «Уверенность имени» и
  «Уверенность переноса». Строка уходит на «проверку», если ЛЮБОЕ из чисел ниже порога;
  выдуманная папка снижает только уверенность переноса, а имя может остаться уверенным.
  Старую карту с единой «Уверенность» программа читает и раскладывает в обе колонки.
- **Просмотр переверстан**: содержимое ~70% окна, панель решения сбоку прокручивается;
  видно старый путь (копируется), папка выбирается кнопкой 📁 из проводника;
  переключатель показа «имя / имя+путь / путь»; текст выделяется и копируется.
- **Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A** работают во всех полях; колесо мыши крутит
  все страницы, включая Настройки; стиль просмотра приведён к общей теме.
- **Оригиналы после конвертации**: кнопка ищет `.doc/.rtf/.odt`, у которых уже есть
  `.docx`, и кладёт список в «Корзину» (перенос, не удаление).
- «Имена: предложения» теперь пишет вывод в `name_repairs.csv`, а не только счётчик.
- Промпт усилен приоритетами выбора папки: существующие папки и корни («По собору…»,
  «Личное…») важнее выдуманных; свалки вида «Разное» запрещены; `reason` обязан
  сравнить 2–3 кандидата.

> **Программа не удаляет файлы.** Она перемещает и переименовывает утверждённое,
> ведёт журнал операций и откатывает последнюю пачку. Лишнее (пустое, битое,
> дубли) предлагается убрать в отдельную папку «корзины» — уже оттуда вы удаляете
> вручную. Совпадение имён даёт `_v2`, перезаписи нет ни в одном сценарии.

## Как открыть

Двойной щелчок по `launch.bat`: проверит Python и Ollama (при необходимости
запустит локальный сервер с вашим хранилищем `E:\.ollama\models`), покажет
диагностику и откроет окно. Из командной строки — `python app.py`, список команд
`python app.py -h`.

Интерфейс: светлый, с мягким градиентом фона, «стеклянными» карточками,
кнопками-пилюлями (подсветка при наведении, лёгкое давление при нажатии),
скользящим переключателем режимов и плавной сменой страниц. Каждая страница
прокручивается колесом мыши — длинные настройки больше не прячутся.

## Режимы работы

- **🧹 Разбор завалов** — очередь из `Документы/00_Разобрать`: каждому файлу ищется
  постоянное место.
- **🧭 Ревизия структуры** — очередь по постоянной структуре (зона разбора
  исключена): проверяем имена и типы там, где файлы уже лежат.
- **🔍 Вся система** — всё подряд, поиск ошибок раскладки.
- **🪜 Система → потом разбор** — сначала проходим по постоянным папкам и наводим
  порядок в них, файлы из «Разобрать» встают в очередь после них: новое не попадёт
  в старые завалы.

Режим сохраняется в `config.json` (`queue.mode`) и меняет установку модели в
промпте: в ревизии менять папку можно только при явной ошибке раскладки.

## Карту системы модель видит целиком

Раньше в промпт попадало всё дерево (≈40 000 токенов) — Ollama отвечала HTTP 500.
Теперь программа подбирает **максимально широкую карту, которая влезает в бюджет**:
от запрошенной глубины вниз, жертвуя сначала глубиной ветки самого файла, потом
подбором по названию, и лишь в последнюю очередь счётчиками файлов.

Ваши цифры: карта системы без «Разобрать» — **615 путей, 5 ярусов, ~8 300 токенов**.
Ветка `00_Разобрать` (и `02_Разобрать`) из карты **скрыта**: её внутренняя структура
ошибочна. Вместо неё в запрос кладётся отдельная строка «текущее место — только
подсказка», а если файл лежит в мусорной папке (`Загрузки`, `Telegram`,
`Рабочий стол`), программа прямо пишет модели, что ориентироваться надо на содержимое.

### Из чего складывается контекст и почему 32 768

Длинная инструкция тоже ест контекст — и он считается теперь честно:

```
num_ctx 32 768 = инструкция ~8 100  +  карта ≤8 500  +  файл ≤3 500  +  ответ ≤800
измерено живым запросом: 18 143 токена из 32 768
```

При прежнем `num_ctx` 16 384 этот же набор не влезал (нужно ~18 500), и Ollama
**молча отрезала начало** — то есть инструкцию отдела. Поэтому:

- бюджет карты считается от `num_ctx` за вычетом фактической длины `prompt.md`
  и текста файла (`slice_budget`), а не по жёсткой константе;
- перед отправкой запрос проверяется (`Analyzer._fit`): если тесно, сначала
  пересобирается карта меньшего яруса, и только потом ужимается текст файла —
  инструкция остаётся целой;
- после ответа сравнивается `prompt_eval_count` с `num_ctx`: упёрся — в журнал
  и в поле «Контекст» строки попадает предупреждение;
- проверить самому: страница ✨ Промпт → «🔎 Проверить промпт», либо `python app.py doctor`.

32 768 — потолок для RTX 3060 12 ГБ с gemma3:12b: модель с таким контекстом занимает
~9 ГБ (из них ~7,8 ГБ в видеопамяти) и работает. 65 536 уже упрётся в обмен с
оперативной памятью и затормозит. Если поднимете — поднимайте и `content_chars`.

Если промпт всё же займёт больше 92 % контекста, бюджет следующего среза
уменьшается автоматически; при HTTP 500 срез пересобирается и запрос повторяется
(до трёх попыток).

## Чему программа не верит

- **дата и год** в имени обязаны подтверждаться текстом, старым именем или датой
  изменения — распознаются и «09.05.2026», и «9 мая 2026»; иначе строка на проверку;
- **выдуманная папка**: если её нет в реальном дереве, уверенность режется до
  потолка (по умолчанию 0.80) и строка идёт на проверку;
- **`target_path` — только папка**: вернувшееся вместе с путём имя файла отрезается;
- **написание**: путь сопоставляется с деревом нечувствительно к `ё/е` и регистру —
  «Отчёты» и «Отчеты» это одна папка, настоящее написание (`ё`) сохраняется;
- **несколько документов в одном файле** (несколько заголовков типов, переводов
  страниц, приложений, разные даты) — предупреждение проверяющему, на автоприменение
  не выходит;
- **корневой раздел** сверяется со списком регламента, опечатка исправляется
  мягким сопоставлением; если рядом есть похожая папка — берётся существующая;
- **направление и номер**: блок `Вх-`/`Исх-` в имени и поле `direction` обязаны
  совпадать; дата в имени сверяется с `doc_date`, а многодневное событие не должно
  «сжиматься» до одного дня (`event_start`/`event_end`);
- **служебные папки в «Мероприятиях»** (`non_event_folders`: «Отчеты и планы по
  работе», «Босовец», «Ткаченко», «Отдел спорта») не принимаются как папка события;
- **двойники** одного события сводятся к канону по `folder_aliases` (в карте это
  «Форум „Жизнь вечная“» с разными кавычками и пробелами) — с пояснением в строке;
- **ярлык письма о событии**: если модель не указала `shortcut_to`, программа сама
  добавляет `Входящие/ГГГГ` или `Исходящие/ГГГГ` по направлению и дате письма,
  а при переносе создаёт там `.lnk` (или `.url`, если WSH недоступен) — при откате
  ярлык не удаляется, а уносится в `orphan_shortcuts`;
- оставить файл в зоне «Разобрать» можно только с `review=true`;
- сканы без текста и фото идут в зрение модели, а если зрения нет — на проверку;
- старые `.doc`, битые файлы, совпадения по содержимому, уверенность ниже порога —
  на проверку;
- файла нет на диске (снимок устарел) — в очередь не попадает, программа просит
  обновить снимок.

Строки «проверка» к применению не отмечаются. Утвердить разом всё помеченное —
кнопка «✅ Утвердить помеченные» (строки «проверка» станут «готово»).

## Промпт

Два редактируемых файла рядом с программой:

- `prompt.md` — системная инструкция (роль, принципы, именование, куда класть,
  примеры, правило «не выдумывай подпапки», предложение корзины);
- `prompt_user.md` — шаблон запроса про файл (`{mode_line}`, `{folders_block}`,
  `{content}` и др.).

Правятся в любом редакторе или на странице ✨ Промпт; «Вернуть образец»
восстанавливает заводской текст; «Показать запрос строки карты» выводит ровно то,
что уйдёт в модель, с оценкой токенов.

## Возможности (🧩 Плагины)

| Возможность | Что даёт | Что нужно |
| --- | --- | --- |
| Распознавание текста (OCR) | читает сканы PDF и фото — файл перестаёт быть «только глазами» | Tesseract-OCR с русским языком **и** `pip install pytesseract Pillow` |
| Конвертация старых форматов | `.doc`, `.rtf`, `.odt` → `.docx` рядом с оригиналом | Microsoft Word (pywin32) или LibreOffice |
| Метаданные фото, аудио, видео | дата съёмки, разрешение, длительность, теги | Pillow; для аудио/видео ещё `ffprobe` в PATH |
| Починка битой кодировки имён | возвращает кириллицу в именах из архивов | ничего |
| Поиск битых файлов | пустые, обрезанные, с чужой сигнатурой | ничего |
| Корзина отдела | кандидаты на выброс и перенос в папку корзины | ничего |
| Чтение текстовых PDF / XLSX | извлечение текста | PyMuPDF, openpyxl |

«Установить выбранное» запускает pip и показывает вывод, после успеха возможность
включается. Важно: для OCR одной команды мало — нужен сам Tesseract (UB-Mannheim,
галочка *Additional language data → Russian*), иначе останется нерусский текст.
Проверить: `tesseract --version`.

## Настройки

| Поле | Смысл |
| --- | --- |
| `mo_root` / `scan_root` | корень отдела и корень обхода; пути в карте относительные от `scan_root` |
| `root_candidates` | варианты корня отдела на разных компьютерах (тот же Drive под разными буквами: `T:\…`, `E:\…`); страница ⚙️ Настройки → «Варианты корня» |
| `auto_pick_root` | `true` — при запуске берётся первый существующий путь из `mo_root` + `root_candidates`, а `scan_root` и `output_dir` автоматически переезжают под ту же букву диска |
| `quarantine_dir` | папка корзины (по умолчанию `99_Корзина на проверку`) |
| `llm.num_ctx` | 32768 — полная инструкция + полная карта + текст файла (на RTX 3060 12 ГБ это потолок для gemma3:12b); 16384 уже не вмещает длинный `prompt.md` |
| `llm.content_chars` | сколько текста файла уходит в модель (9000 ≈ 3500 токенов) |
| `llm.cache_policy` | `unload` — полный сброс KV-кэша перед каждым файлом (контекст чист, но медленнее); `nonce` — изоляция запроса без перезагрузки; `none` — без изоляции |
| `llm.vision` | зрение модели для картинок и PDF-сканов |
| `folders.depth`, `max_paths`, `budget_chars` | пределы карты папок |
| `folders.hide_prefixes` | ветви, скрытые от модели (зона разбора) |
| `thresholds.min_confidence` | порог автодоверия |
| `thresholds.new_folder_max_confidence` | потолок уверенности, если папка выдумана |
| `non_event_folders` | папки внутри «Мероприятий», которые не события |
| `folder_aliases` | двойники → канон («левый путь»: «канонический путь») |
| `queue.mode` | режим работы |
| `plugins.*`, `plugins.tesseract_cmd` | включённые возможности; путь к `tesseract.exe`, если он не в PATH |

## Скорость

Gemma 3 12B: ~6 секунд на документ, ~12 секунд на PDF-скан со зрением, дольше при
`cache_policy=unload` и большой карте папок — модель каждый файл стартует с чистого
контекста. Время и расход токенов видны в журнале и в панели деталей строки. Для
черновой прогонки быстрее `gemma4:latest`.

## Кому передаёте программу

Нужны три вещи, ничего «веб-серверного»:

1. **Сама программа** — уже собрана: `Архивариус.exe` (~44 МБ, Python не нужен).
   Рядом с exe должны лежать `config.json`, `prompt.md`, `prompt_user.md` и
   `logo.png` — это редактируемая часть, в exe она не встроена. Пересборка при
   желании: `pyinstaller --onefile --windowed --icon logo.ico app.py` (в этом
   окружении добавьте список --exclude-module, иначе exe раздуется до 300+ МБ).
   Совет: exe держите на локальном диске (с сетевого распаковывается заметно
   дольше). В собранную версию намеренно не включён Word COM: конвертация .doc
   в exe идёт через LibreOffice, через Word — только из Python-папки.
2. **Python 3.11+** — только если без exe (зависимости: `pip install -r requirements.txt`).
3. **Ollama + модель** (~8 ГБ) — `ollama pull gemma3:12b`. В exe это всё равно
   остаётся: модель в один файл не пакуется. Нет видеокарты — укажите в
   «Настройках» адрес чужой Ollama в локальной сети (`base_url`), программа
   умеет ходить по HTTP.

Буква диска у получателя может быть любой: путь отдела хранится списком
вариантов (Настройки → 📁 Пути), при запуске берётся первый существующий.
Перед первым разбором отделу другого профиля замените `prompt.md` и
`top_folders` — код трогать не нужно.

## Чего программа не делает

Не удаляет и не перезаписывает файлы; не трогает неотмеченное; не отправляет
содержимое в облако; не создаёт ярлык Google Drive. Для письма о событии программа
кладёт в папку Входящие/Исходящие настоящий ярлык Windows `.lnk` (а если Windows
Script Host недоступен — `.url`, и лишь в крайнем случае текстовый указатель
`ярлык_имя.txt`). При переносе папки в Google Drive обычный `.lnk` не является
ссылкой облака — замените его ссылкой Drive, если она нужна.
